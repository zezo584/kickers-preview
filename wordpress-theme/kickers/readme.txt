=== Kickers Foods ===
قالب ووردبريس مخصص لشركة كيكرز للصناعات الغذائية — عربي أساسي + إنجليزي.

== التثبيت ==
1. خد نسخة احتياطية من الموقع.
2. المظهر ← قوالب ← أضف جديد ← رفع قالب ← kickers-theme.zip ← تفعيل.
3. المظهر ← "كيكرز: البداية السريعة" ← استيراد المحتوى (تصنيفات، 6 علامات، 17 منتج بصورهم، 4 بانرات، صفحات من نحن وتواصل، أيقونة الموقع = الشعار).
4. الإعدادات ← روابط دائمة ← حفظ (مرة واحدة).
5. (اختياري) عطّل Elementor والإضافات القديمة لو مش محتاجها — القالب مش محتاج أي إضافة.

== التعديل ==
- المنتجات: القائمة الجانبية ← المنتجات (اسم عربي/إنجليزي، وصف، وزن، صورة، لون الكارت، "اعرض في الرئيسية").
- التصنيفات والعلامات التجارية: المنتجات ← التصنيفات / العلامات التجارية.
- البانرات: بانرات السلايدر — نوعين: تصميم متحرك (نص + صور منتجات) أو صورة جاهزة كمبيوتر/موبايل. الترتيب من "الترتيب".
- كل النصوص، التليفونات، واتساب، السوشيال، إظهار/إخفاء الأقسام، SEO: المظهر ← تخصيص ← إعدادات كيكرز.
- رسائل نموذج التواصل: القائمة الجانبية ← رسائل التواصل + بتوصل على الإيميل.

== الإنجليزي ==
نفس الروابط بعد /en/ (مثال: /en/products/). كل منتج/صفحة/تصنيف ليه خانات إنجليزي.

== SEO ==
عناوين ووصف لكل صفحة، canonical و hreflang (ar/en)، Open Graph، Schema (Organization, Product, Breadcrumb)، خريطة موقع wp-sitemap.xml + wp-sitemap-en-1.xml، وتحويل 301 للروابط القديمة (services، بسكويت-محشو ...).
لو مركّب Yoast أو Rank Math أو SureRank، القالب بيسيب الوصف والمشاركة للإضافة ويحتفظ بالـ hreflang.
