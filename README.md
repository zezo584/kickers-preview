# Kickers Foods – new website

Redesign of [kickersfoods.com](https://kickersfoods.com/) (Kickers Food Industries) — Arabic first, with an English version.

**Live preview:** https://zezo584.github.io/kickers-preview/

| Path | What it is |
|---|---|
| `index.html` + `assets/` | Static, clickable preview of the whole site: home with the animated banner slider, products (filters by category/brand), product pages, about, contact. AR/EN switch in the header. |
| `kickers-theme.zip` | Installable WordPress theme *(added in the next commit)*. |
